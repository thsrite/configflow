### Spike results (`run.sh` on .32 against a private copy of the snapshot; `splice/` on .63)

- **JSON:** every stored field is valid for `encoding/json`; no `NaN`/`Infinity`, no integer beyond 2^53,
  no integral floats written as `x.0`, no duplicate object keys, no lone surrogates. An order-preserving
  token re-encode (`encoding/json` strings, `SetEscapeHTML(false)`, numbers as written) reproduces **43/43
  rows byte for byte**.
- **YAML loads:** all 24 YAML texts of the snapshot (10 stored text fields, 14 files under `DATA_DIR`) load to
  the same value with yaml.v3 as with PyYAML `safe_load`; no CRLF, no multi-document text.
- **Node round trip:** yaml.v3 Node → encode (indent 2) → parse keeps the value of all 24 and every comment of
  the one commented file; it drops blank lines (1 file).
- **yaml.v3 facts used below:** a Node parse accepts duplicate keys, `Decode` refuses them (`already
  defined`); the encoder quotes strings that a YAML 1.1 reader would type (`yes`, `on`, `0777`, `1:30`,
  `1_000`, dates), so PyYAML and Mihomo read Go output the same; no line wrapping; anchors/merge keys
  survive a Node round trip; CRLF input with comments parses; `0777` decodes as 511, `1:30` as a string; a
  timestamp decoded into `any` is a `time.Time`; a JSON surrogate pair parses correctly; a second document
  is silently ignored by `Unmarshal`.
- **Splice editor:** yaml.v3 `Line`/`Column` (columns in runes) locate single-line scalars exactly in block,
  flow, quoted, escaped, CJK and CRLF documents; in-place replacement keeps every other byte; re-parsing
  catches the anchored-listener case where an in-place edit would also change the anchor's other users.

## 1. Scope

In scope:
1. **N7** — `internal/pyyaml`, the PyYAML-port loader/constructor/emitter in `internal/yamlx` and
   `internal/subs/commented` are replaced by a new `yamlx` on `gopkg.in/yaml.v3` (load, dump, dynamic
   documents as `*yaml.Node`, JSON↔Node, comment-preserving edit). oxidns' private Node helpers move into it.
2. **N8** — `internal/jsonx` is deleted. Stored documents become typed records (`internal/model`) with
   byte-preserving round trip of unknown and unchanged members; `internal/store` works on raw rows;
   `internal/repo` gets a typed API; HTTP requests/responses use `encoding/json`.
3. The **S passes** that the swaps force on their consumers (all packages in the survey table), including
   S-convert and S-provider (remove `any` parameters, `dictGet`, `raise`/`catch`, `must`, `pyError`).
4. C11 open item (1) CRLF refusals and items (2)/(3) of the editor: resolved by the new editor (section 5.5).

Not in scope (explicitly):
- `pystr` (N3), other per-package Python value glue not caused by jsonx (N10) and exception emulation
  outside convert/provider (N9) — the S passes remove such code when they rewrite a function anyway, but
  do not chase it package-wide.
- Database schema, storage version, SQLite locking and background-task scheduling (O3). The store schema and
  row layout stay exactly as they are; Python and Go stay interchangeable on the file.
- Byte format of generated YAML/JSON (functional parity: semantics only), and of stored JSON for members
  that change.
- New features, the switch itself, Agent binary changes.

## 2. Interface contract

### 2.2 `yamlx` (rewritten; replaces `pyyaml`, old `yamlx`, `subs/commented`, `oxidns/node.go` helpers)

```go
package yamlx // Package yamlx is the one place the server reads and writes YAML, on gopkg.in/yaml.v3.
              // Dynamic documents are *Node trees. It does not know any document schema.

type Node = yaml.Node

// Reading
func Parse(src []byte) (*Node, error)          // one document; returns the content node (never DocumentNode);
                                                // empty text → null scalar. Policies below.
func Unmarshal(src []byte, v any) error         // Parse + Decode
func Decode(n *Node, v any) error               // typed decode of a (sub)tree; aliases followed

// Writing
func Marshal(v any) ([]byte, error)             // v: *Node or typed value; indent 2, LF, no wrapping
func Encode(v any) (*Node, error)               // typed value → Node (yaml tags)

// Building and navigating (moved from oxidns/node.go; one shared copy)
func Map(pairs ...*Node) *Node   // key, value, key, value…
func Seq(items ...*Node) *Node
func Str(s string) *Node; func Int(i int64) *Node; func Float(f float64) *Node; func Bool(b bool) *Node; func Null() *Node
func Get(m *Node, key string) *Node             // nil when absent or m is not a mapping
func Set(m *Node, key string, v *Node)          // replace in place or append
func Delete(m *Node, key string) bool
func Pairs(m *Node) iter.Seq2[string, *Node]    // string keys in order
func Resolve(n *Node) *Node                     // follows aliases
func Clone(n *Node) *Node                       // deep copy; aliases become copies (no shared nodes)
func Equal(a, b *Node) bool                     // structural: mapping order ignored, scalars by resolved
                                                // tag + value (numbers by value), aliases resolved

// JSON documents as Nodes (stored dynamic fields, JSON payloads read generically)
func FromJSON(data []byte) (*Node, error)       // encoding/json tokens → Node; member order and number
                                                // text kept; duplicate members: last wins
func ToJSON(n *Node) ([]byte, error)            // compact; strings via encoding/json without HTML escaping;
                                                // non-JSON scalars (timestamps, binary) written as strings

// Comment-preserving edit
func Edit(src []byte, edit func(doc *Node) error) ([]byte, error)

var (
    ErrSyntax            = errors.New("yamlx: invalid YAML")        // wrapped by *SyntaxError
    ErrDuplicateKey      = errors.New("yamlx: duplicate mapping key") // also ErrSyntax
    ErrType              = errors.New("yamlx: incompatible YAML type") // also wraps *yaml.TypeError
    ErrMultipleDocuments = errors.New("yamlx: more than one document")
    ErrUnsafeEdit        = errors.New("yamlx: edit cannot keep the rest of the text")
)
type SyntaxError struct{ Line, Column int; Problem string }        // errors.Is(err, ErrSyntax)
```

**Load policies (decided once here; every reader of user YAML goes through `Parse`/`Unmarshal` — WORKFLOW
note from R01):**
- More than one document → `ErrMultipleDocuments` (Python's safe_load refused too; same accept/reject set).
- Duplicate mapping keys → **decision D1: reject everywhere**, naming the duplicate key and its line.
- A leading BOM is skipped; CRLF/CR line ends are accepted (yaml.v3 handles them).
- YAML 1.1 implicit types follow yaml.v3 (accepted 2026-11-16): `yes/no/on/off` are strings, `0777` is 511,
  `1:30` is a string. Timestamps stay scalar text in Nodes and decode to `time.Time` only into a typed
  `time.Time` field. `!!binary`, `!!set`, `!!omap`, `!!pairs` are kept as Nodes and passed through.
- Mapping keys that are not strings are kept in the Node; `Pairs` skips them; typed decoding follows yaml.v3.

Chinese diagnostics for facade policy checks are constants in `yamlx/messages.go`, following AGENTS.md.
Callers wrap with their own context constants (`fmt.Errorf(msgMihomoBaseInvalid…)` in their
`messages.go`); a user-facing message that used to embed a PyYAML text now embeds yaml.v3's.

**Clarified in N7-1 (coordinator, 2026-11-17):**
- `Parse`, `Decode` and `Marshal` reject recursive references with a `SyntaxError` wrapping `ErrSyntax`;
  the Chinese diagnostic names the line. `Clone` expands aliases into independent copies; for a manually
  constructed cycle it replaces the back edge with `Null` rather than panicking or retaining a cycle.
- `Get` follows YAML merges, with explicit keys overriding inherited values. `Pairs` returns effective
  keys (inherited keys first, with first-source precedence); `Equal` compares merged and expanded mappings
  as equal. `Delete` materialises merges so a deleted inherited value cannot reappear.
- Alias expansion uses yaml.v3 v3.0.1's decoder budget: more than 100 alias-driven operations, more than
  1000 total operations, and an alias-operation ratio above the allowance (99% through 400k operations,
  scaling to 10% at 4m). Ordinary document nodes are never subject to a size limit. The same check protects
  `Parse` and other facade paths; `Clone` replaces an over-budget manual expansion with `Null`.
- Timestamps retain their original text in Nodes. For decoding, only generic interface subtrees treat
  timestamps as `!!str`; typed `time.Time` destinations retain the timestamp tag.
- `ToJSON` writes YAML non-finite numbers (`.inf`, `-.inf`, `.nan`, including alternate spellings) as
  strings containing their original scalar text, like other non-JSON scalars. This differs deliberately
  from N8-1's HTTP response writer: a non-finite Go numeric value there becomes JSON null.
- Typed `Decode` mismatches wrap `ErrType` and the original `*yaml.TypeError` (both `errors.Is` and
  `errors.As` work). They are not `ErrSyntax`; their Chinese context is a messages.go constant.
- N7-2 correction to N7-1: Marshal normalises FoldedStyle to LiteralStyle, preserving the actual
  scalar value and avoiding yaml.v3's extra-newline bug around more-indented folded continuations.
- N7-2 correction to N7-1: Marshal moves a sequence/mapping key's LineComment above its pair
  (HeadComment), retaining the text and avoiding invalid yaml.v3 output before the colon; scalar keys keep
  their comment placement. Parse→Marshal→Parse must preserve semantics.
- N7-2 correction to N7-1: strings containing Tab are emitted with DoubleQuotedStyle, retaining
  TaggedStyle; literal/folded output can make Tab-only or Tab-leading lines unparsable by yaml.v3.
- N7-1 adds APIs alongside the legacy implementation only. Consumer migration, including oxidns' helper
  removal, belongs to subsequent steps; no runtime caller is switched in this step.

**Clarified in N7-2 (coordinator, 2026-11-17):** duplicate keys also match `ErrDuplicateKey` through
`errors.Is`; the wrapping `SyntaxError` exposes `*DuplicateKeyError{Key, Line}` through `errors.As`.
The subs relink boundary appends the native parse diagnostic after its existing Chinese context;
other listener validation messages stay unchanged. Real proxy-groups route differential coverage belongs
to C33; N7-2 covers the public relink boundary and a transactional test HTTP shell, not a new route.

**Clarified in the N7-2 review (Opus, 2026-11-17; parity/review-n7-2.md):**
- A splice whose output fails verification falls back to the re-encode path (D3) instead of
  `ErrUnsafeEdit`; indentless block-sequence entries belong to a removed pair. The re-encode path
  verifies against a copy of the caller's edited Node taken before any preparation step.
- Re-encoding never expands aliases: when an anchor definition was removed or moved after its use,
  the first remaining consumer becomes the definition (anchor kept) and later consumers stay aliases.
  `Clone` (over-budget → `Null`) is not used on user documents; a subtree of an accepted document
  can exceed the alias budget on its own.
- Comments of removed pairs are placed before the sequence item that held the mapping, or before the
  next key of any other mapping; other orphaned notes still go to the document head.
- `Marshal` writes an untagged plain merge key as `<<` (yaml.v3 would write `!!merge <<`) and quotes
  a string `<<` (yaml.v3 would write it plain, which reads back as a merge key). Every string scalar
  reads back as the same string.
- `Parse` reports more than one document with a Chinese `messages.go` diagnostic naming the line of
  the second document; it still matches `ErrMultipleDocuments`.
- Node validation (Parse, Decode, Marshal) rejects the tag `!!` without a type name (from `!%21` or
  `!<tag:yaml.org,2002:>`) with a `SyntaxError`: yaml.v3 cannot write it back; PyYAML refused it too.
- Relink copies only containers that an alias or anchor makes reachable from elsewhere (one level,
  children shared and unexpanded, like Python's `deepcopy`); unshared listeners are edited in place.

**`Edit` contract.** `Edit` parses `src` with positions, calls `edit` on the document Node, then writes the
result in one of two ways and verifies it:
1. *Splice* — when every change is (a) a single-line scalar whose value changed and that is not reachable
   through an anchor used elsewhere, or (b) the removal of a mapping pair that occupies whole lines in a
   block mapping and is not the first key after `- `: the bytes of exactly those tokens/lines are replaced
   or removed (new scalars written with `Marshal` of a string Node, i.e. quoted when needed). Comments,
   blank lines, quoting style, indentation and the line-end style of every other line are kept.
2. *Re-encode* — otherwise: the edited Node is written with `Marshal` (comments kept by yaml.v3; blank
   lines and layout normalised); if `src` used CRLF throughout, the output uses CRLF.
3. *Verify* — the output is parsed again and must be `Equal` to the edited Node; otherwise `ErrUnsafeEdit`
   and the caller keeps the original text (the existing 400 path, message unchanged).
Change detection compares each scalar's value with a snapshot taken before `edit` runs (pointer → old
value/tag) and records removed pairs; nodes added by `edit` force the re-encode path. Whether step 2 is
enabled depends on decision **D3** (with D3 = B, step 2 returns `ErrUnsafeEdit` instead).

### 2.3 `model` (new leaf package: the stored document as Go types)

```go
// Package model defines the configuration document stored in configflow.sqlite3 as Go types
// (profiles, shared resources, system). It keeps every member it does not declare and writes unchanged
// members back byte for byte. It does no I/O and holds no behaviour beyond encoding and small accessors.
package model

type Document struct {               // root: schema_version, system, shared, profiles + unknown root fields
    System   System
    Shared   Shared
    Profiles []*Profile               // stored order (section positions)
    Root     Fields                   // other root fields, e.g. schema_version
    order    []string                 // root key order as stored
}
type Profile struct {
    ID, Name, Description, CreatedAt, UpdatedAt string
    Revision        int64               // _revision
    ProxyGroups     []ProxyGroup        // field-by-field typing, see steps M1–M6
    RuleConfigs     []RuleConfig
    Mihomo          MihomoSettings
    Surge, Loon     ClientSettings
    MosDNS          MosDNSSettings
    OxiDNS          Dynamic            // stays dynamic (yaml Node via yamlx.FromJSON)
    Routers         Routers
    DomainDiscovery DomainDiscovery
    DeviceNotes     Map[DeviceNote]
    ClientFixedIPs  Map[ClientFixedIP]
    Fields          Fields             // members not declared above, in stored order
}
// Shared {Subscriptions, Nodes, Aggregations, RuleLibrary, Revision, Fields}; System {SystemConfig, Backup,
// Agents []Agent, Revision, Fields}; Config = the resolved per-profile view (repo.GetConfig), same field
// names as Python's compat config.
```

Core codec (the only reflection-based code; ~300 lines with tests):

```go
// Raw is what a record was decoded from: its members in order, as bytes. It is immutable after
// decoding, so copying a record (and sharing Raw) is safe.
type Raw struct{ /* unexported: []member{name string; value json.RawMessage; known, invalid bool} */ }

func DecodeRecord(data []byte, rec any, raw *Raw) error  // rec: pointer to struct
func EncodeRecord(rec any, raw *Raw) ([]byte, error)

// Every record type:
func (g *ProxyGroup) UnmarshalJSON(b []byte) error { return DecodeRecord(b, g, &g.raw) }
func (g ProxyGroup) MarshalJSON() ([]byte, error)  { return EncodeRecord(&g, &g.raw) }

type Map[V any] struct{ /* ordered keys + values; JSON object codec keeps member order */ }
type Fields struct{ /* ordered name → json.RawMessage (whole section members not typed yet) */ }
type Dynamic struct{ raw json.RawMessage }  // Node() (*yaml.Node, error) / SetNode(*yaml.Node) error

func Marshal(v any) ([]byte, error)  // json.Encoder, SetEscapeHTML(false), no trailing newline — the
                                     // only JSON writer for stored data (encoding/json's Marshal would
                                     // re-escape <>& inside preserved bytes)
```

Record codec rules (they are the stored-data compatibility guarantee; reviewers check every type):
- **R1 Unknown members** are kept in place (position and bytes).
- **R2 Unchanged members are written as they were read.** A known member is "unchanged" when
  `Marshal(current)` equals `Marshal(decode(original))` of the same Go type; then the original bytes are
  written (keeps `null`, `1.0`, escapes, nested order). Changed members are written with `Marshal`.
- **R3 Presence.** A member present in the original stays present (written even when zero). A member absent
  in the original is written only if it is not the zero value (`omitzero` semantics), appended in struct
  order. Removing a member requires a pointer field set to `nil` (or `Fields.Delete`).
- **R4 Defaults that are not Go zero values** (Python `obj.get('enabled', True)`) are pointer fields or a named
  type with an accessor (`func (g ProxyGroup) Enabled() bool`), never a plain `bool` — otherwise writing
  `false` and reading "absent" disagree.
- **R5 Wrong JSON type in stored data** (e.g. a string where a list is declared): the member is kept as
  stored, the field reads as its zero value, a warning is logged once per load (`logx`, path only, no value),
  and the original bytes are written back unless code assigns a non-zero value. Loading never fails because
  of one bad member (no lock-out from the UI).
- **R6 Maps keyed by user data** (device ids, domains, policy names) are `Map[V]` (order kept); Go `map` only
  for maps whose order is irrelevant and never written back.
- **R7 Free-form sub-trees** that the code navigates without a fixed schema stay `Dynamic` (→ `*yaml.Node`
  via `yamlx.FromJSON`), never `map[string]any`. Opaque values that are only carried are `json.RawMessage`.
- **R8 Numbers (stored data; O6 X04).** Python wrote whatever its handlers accepted, so a stored integer
  member may hold `60`, `60.0`/`6e1` (float), or `true`. The model reads by meaning, not by Python type:
  integer members are `model.Int` (an `int64` whose `UnmarshalJSON` accepts an integral JSON number in any
  notation — `60`, `60.0`, `6e1` — and nothing else); fractional members are `float64`; members that may
  exceed int64 are `json.Number`. Anything else (`true`, `"60"`, `60.5` in an integer member, `NaN`) is a
  wrong-typed member under R5 (kept as stored, reads as zero, logged). Because of R2 the stored text
  (`60.0`) is written back unchanged unless the value changes; a changed value is written in Go's form
  (`61`). Python-side distinctions such as `type(x) is int` are request validation (section 2.6), not
  storage rules. A type is accepted only after the round-trip test (section 5.2) passes on every corpus.
- **R9 No `any`** in model types except where the stored value is genuinely polymorphic and documented; then
  a named type with `UnmarshalJSON` that records which form was stored.

**Clarified in N8-3 (maintainer/coordinator, 2026-11-17):**
- Model remains a leaf depending only on the standard library and yamlx, with no I/O or
  dependency on logx. Decoding collects `[]model.FieldIssue` containing only a schema path
  and error category, never a stored value or raw error text. Repo records these through
  logx once per loaded revision, including when the decoded document is too large to cache.
- `encoding/json` compacts RawMessage and MarshalJSON output. To uphold R1/R2, model
  records, RawMessage values and containers are assembled from validated original JSON
  fragments; newly produced/changed scalar values use a native Encoder with
  SetEscapeHTML(false). This is a byte-preserving record codec, not a Python encoder.
- Codec invariants: output is UTF-8 JSON accepted by json.Valid; object member names
  are unique; existing member order and unchanged member bytes survive; new members
  follow R3; original metadata stays immutable. Duplicate JSON members are rejected
  rather than emitted or silently dropped. Fuzzing and stored-row round trips assert
  these invariants. FieldIssue paths use schema names and numeric indices so user map
  keys, identifiers, passwords and tokens cannot leak into diagnostics.

### 2.4 `store` (raw rows)

```go
type Field   struct{ Name string; Value json.RawMessage }
type Section struct{ Fields []Field }                     // stored order
type Document struct {
    Order    []string                                     // root_order
    Root     []Field
    System, Shared *Section                               // nil when absent
    Profiles []ProfileRows                                // by stored position
}
type ProfileRows struct{ ID string; Fields []Field }
type Meta struct{ StorageVersion int; StoreID string; Generation int64; CommitID string; RootOrder []string; CreatedAt string; Extra map[string]json.RawMessage }
type Entry struct{ Head Head; Document *Document; Size int64 }   // Document immutable

func (s *Store) Load() (Entry, error)
func (s *Store) Commit(base Entry, doc *Document, meta map[string]json.RawMessage) (Entry, bool, error)
// Create, BuildTemporary, Install, Check, BackupTo, PreserveCorrupt, … unchanged apart from types.
```

The store never parses field values; it checks `json.Valid` before writing (`ErrDocument`). The commit diff
compares bytes, so a field whose bytes did not change is never rewritten and keeps its revision.
`Fingerprint` becomes a Go-defined digest (length-prefixed rows); it is only used by tests, and tests that
compared it with Python compare rows instead. Error kinds and Chinese messages stay.

### 2.5 `repo` (typed API; legacy jsonx API kept until step N8-11)

```go
// Reads: each call returns a value the caller owns (decoded from the immutable committed rows).
func (r *Repository) Profile(ctx context.Context, id string) (*model.Profile, error)
func (r *Repository) Shared(ctx context.Context) (*model.Shared, error)
func (r *Repository) System(ctx context.Context) (*model.System, error)
func (r *Repository) Config(ctx context.Context, profileID string) (*model.Config, error)   // = GetConfig
// Shared read-only snapshot for hot paths (generation, heartbeats): decoded once per committed head.
// fn must not modify or retain anything it reads.
func (r *Repository) View(ctx context.Context, fn func(d *model.Document) error) error

// Writes: one transaction each, under the existing .config.lock + in-process lock.
func (r *Repository) Update(ctx context.Context, fn func(ctx context.Context, d *model.Document) error) error
func (r *Repository) UpdateProfile(ctx context.Context, id string, fn func(ctx context.Context, p *model.Profile) error) (revision int64, err error)
func (r *Repository) UpdateShared(ctx context.Context, fn func(ctx context.Context, s *model.Shared) error) error
func (r *Repository) UpdateSystem(ctx context.Context, fn func(ctx context.Context, s *model.System) error) error
func (r *Repository) UpdateSharedAndProfiles(ctx context.Context, fn func(ctx context.Context, s *model.Shared, profiles []*model.Profile) error) error
// Request-scope helpers keep their semantics on typed values:
func GetConfig(ctx context.Context, profileID string) (*model.Config, error)
func SaveConfig(ctx context.Context, cfg *model.Config, profileID string) error   // three-way merge vs. the scope baseline
```

- **Three-way merge** (`SaveConfig`, `SafeImportConfig`, shared/system saves with a baseline) keeps Python's
  algorithm but runs on `*yaml.Node` trees: baseline, proposed and current field values are converted with
  `model.Marshal` → `yamlx.FromJSON`, merged per field with `yamlx.Equal`, converted back and decoded. This
  is the one place a whole field is handled generically.
- Errors stay `*repo.Error` with the existing kinds and Chinese messages (moved into `repo/messages.go` as
  constants). Typed decode problems of stored data never surface as errors (rule R5).
- Hooks (`repo.Hooks`) change their parameter types from `*jsonx.Object` to the model types in the step that
  migrates the hook's owner; until then the legacy adapter converts.
- The **legacy API** (`GetConfig` returning `*jsonx.Object`, `UpdateProfileTransaction`, …) is implemented in
  `repo/legacy.go` on top of the typed API by `model.Marshal` → `jsonx.Parse` and back; no logic of its own.
  It is deleted in N8-11.

### 2.6 `httpx`

- **Responses — one exit (O6 X01).** Every JSON body (`JSON`, `JSONStatus`, `Message`, `External`, error
  bodies) goes through one function, `httpx.writeJSON`: (1) encode the Go value with `encoding/json`
  (`SetEscapeHTML(false)`); (2) one streaming pass over the encoded tokens (`json.Decoder`, `UseNumber`) that
  applies the **global redaction policy** — any string containing a current/retired rule-proxy token or an
  Agent token in any of the forms the redaction package recognises (plain, `%`-encoded, repeatedly encoded,
  `+` form) becomes `[REDACTED]`; members named `rule_proxy_token`, `retired_rule_proxy_tokens`,
  `rule_fetch_proxy` are dropped at any depth; a container nested 128 deep becomes `"[REDACTED]"` — honouring
  the per-endpoint exemptions that `internal/redact`/`httpx` already key by endpoint name; (3) sort object
  members (Flask `jsonify`); (4) write. Output is UTF-8, not ASCII-escaped. No handler or package redacts or
  sorts on its own; `External` callers that pre-redacted (`jsonify_external`) get the same result from the
  global pass, which the X01 rows assert. Redaction works on decoded string values, so escaping differences
  (`\u` forms, `\/`) cannot hide a token. Cycles cannot occur in encoded output (Go values encode or fail).
  During migration `*jsonx.Object` implements `json.Marshaler` (N8-1), so mixed values take the same exit.
- **Clarified in N8-1 (coordinator, 2026-11-17).** The bridge preserves insertion order and number
  literal text. After encoding pending Go values (`JSON`/`External`), visit original object keys in sorted
  order before resolving redacted-key collisions (last value wins); `RawJSON` visits keys in input order.
  Final output always sorts keys. This preserves Python's collision behaviour, including a literal
  `[REDACTED]` key. `External` now defers to the same final pass, after hooks and credential rotation.
  N8-1 inventories persisted identities only; it does not migrate them or activate D2's one-time changes.
  Notification fingerprints, router signatures, rule cache paths and hosts digests have frozen regression
  tests; later consumer steps migrate their encoders. No `canonjson` is added (D2 = B).
- **Clarified in N8-1 (coordinator, 2026-11-17): non-finite response numbers.** Every JSON response
  encodes `NaN`, positive infinity and negative infinity as JSON `null`, including stored Agent metrics,
  native floats, legacy numbers and pre-encoded JSON bodies. There is still one native response exit.
  This fixes Python's invalid JSON output (browsers could not parse it; charts can treat null as a missing
  point), rather than preserving its bug. Only the three numeric literals are repaired; strings remain
  strings, finite numbers and all other fields remain unchanged. See `parity/behaviour-changes.md`.
  Agent metrics differential fixtures explicitly assert the known history/summary fields; they do not
  broadly normalize arbitrary numbers. Handling non-finite metrics on ingestion is follow-up A04/A05 work.
- **Requests (O6 X04).** `c.Bind(&dto) error` shares `c.JSON()`'s Content-Type, BOM and empty-body handling
  (`application/json` with parameters and `+json` types count as JSON; `text/plain` → 415 for `request.json`,
  nil for silent; same 400/415 bodies). DTO rule: a field accepts every JSON form the Python handler accepted;
  where the Python validator distinguished JSON forms, the DTO field is `httpx.Number` — the literal text plus
  its form (integer literal, fraction/exponent literal, `true`/`false`, string) — and the validator states its
  rule explicitly in Go (`IsIntegerLiteral()` for Python's `type(x) is int`; `IsIntegerLiteral() || IsBool()`
  for `isinstance(x, int)`); huge integers stay exact (`json.Number`). Duplicate members: last wins (same as
  Python and encoding/json). Lone surrogate escapes decode to U+FFFD. `NaN`/`Infinity`/`-Infinity` are not
  JSON: Go refuses the body with the same 400 as any malformed body (listed in 5.7; browsers never send them).
  Strings coerced with `int()` (query args and string-valued body fields) go through one function,
  `httpx.ParseInt`, whose accepted syntax (whitespace, `+`, `_`, non-ASCII digits) is decided by N3 (`pystr`
  swap), not here; the DTO keeps the raw string so that decision lands in one place. The difftest rows X04,
  R015–R017, R226, R210, H511, R076, R047, R080/R090 are the acceptance. `c.JSON()`/`JSONObject` stay until
  N8-11.
- **JWT (O6 T29).** `auth` stops encoding claims with jsonx. Verification never re-encodes: the HMAC is
  checked over the received `header.payload` segments, then the payload is decoded with `encoding/json` into
  a claims struct (`exp` optional — Python-issued tokens without `exp` stay valid exactly as they were;
  numeric `exp`/`iat` accepted as integer or float). Only the algorithm Python used is accepted; `none` and
  any other `alg` are rejected. Tokens Go issues are encoded with `encoding/json`; byte equality with
  Python-issued tokens is not required.

### 2.7 Persisted encodings (decision D2)

Some JSON text is not a document but an identity that is persisted or compared later: notification
dismissal fingerprints (`notifications/store.go`), rule cache file names (`rules.RuleCacheFilename`,
`json.dumps` spacing is part of the name), subscription hosts digests (`subs.HostsDigest`), router
signatures (`notifications.RouterSignature`), the matcher-cache stamp, Agent monitor target digests, health
latency keys. Step N8-2 inventories every `jsonx.Encode/Sorted/Default/Compact` call site into: response,
stored document, file content, **persisted identity**, transient key, Agent payload. Persisted identities
follow D2.

## 3. State and concurrency

| State | Owner | Mutated by | Notes |
|---|---|---|---|
| SQLite rows | `store` | `store.Commit` inside one `BEGIN IMMEDIATE` | unchanged |
| committed `store.Entry` (raw rows) | `repo` cache | replaced atomically after a commit | immutable; safe to share between goroutines |
| decoded snapshot for `View` | `repo` | built lazily per `Head` (`sync.Mutex` + pointer swap) | read-only by contract; `go test -race` and a debug-build checksum in tests guard it |
| values from `Profile`/`Config`/… | caller | caller | fresh decode, no sharing |
| transaction working copy (`*model.Document`) | the running `Update` | only `fn`, only while it runs | decoded from the base entry at transaction start; reads with the transaction's ctx see it |
| parsed YAML Nodes | caller | caller | `Parse` returns fresh trees; any cache of parsed Nodes hands out `Clone`s |

Transaction semantics (unchanged from today): one writer at a time (`.config.lock` + in-process lock, Python's
lock timeout); a nested write with the transaction ctx returns `ErrInUse` (`不能在配置事务中再次开启写事务`);
`fn` returning an error discards everything; a commit writes only rows whose bytes changed; the
`ConfigurationCommitted` hook runs after the lock is released. Revisions: `_revision` counters are maintained
by repo exactly as now; store row revisions change only for rows whose bytes changed — R2 guarantees that a
Go read-modify-write of one member does not touch other rows.

Cancellation (PORTING rule 4b): repo's write entry points detach cancellation themselves
(`ctx = context.WithoutCancel(ctx)` at the top of `Update*`/`Save*`), keeping the Scope values; a disconnected
browser can no longer abort a commit half-way, whatever the caller passes. Waiting for the lock is bounded by
the lock timeout, not by ctx. Reads honour cancellation. yamlx and model do no I/O and take no ctx.

## 6. Decisions for the maintainer

**Decided by the maintainer on 2026-11-17 (these override the recommendations below):**
- **D1 → reject everywhere** (like Mihomo). Saving a document with a duplicate key returns 400 naming the key and
  line; a stored document with a duplicate key fails generation with the same message in the task status/log (the
  Agent keeps its last good config; nothing is pushed until the user fixes it). The O12 behaviour ledger and the
  release notes must mention it.
- **D2 → Go-native encoding (B)**, no `canonjson`. Consequences accepted: once after the switch dismissed
  notifications reappear and every remote rule is re-fetched. **O14 must warm the rule caches on the Go panel
  before any Agent pulls a new config**, so an unreachable rule source cannot yield a config with missing rules.
- **D3 → whole-document rewrite (A)** when an in-place edit is impossible (comments kept, blank lines/quoting
  normalised).

- **D1 Duplicate YAML keys** in user text (Python: last value wins; Mihomo itself refuses): (A, recommended)
  last value wins in every reader — existing configs keep working, generated output has unique keys;
  (B) refuse with a Chinese message — matches Mihomo, but a stored config with a duplicate key stops
  generating after the upgrade. The production snapshot has none.
- **D2 Persisted JSON identities** (2.7): (A, recommended) one small `canonjson` encoder that produces the
  existing text (sorted keys, chosen separators, `\uXXXX` escaping) used only for persisted identities — no
  re-fetch of rule caches, dismissed notifications stay dismissed; (B) Go's encoding — after the switch
  dismissed notifications reappear once, every remote rule is fetched again (generation is incomplete if a
  source is unreachable at that moment), subscription host digests report one change.
- **D3 Editor re-encode path** (anchored listener sequence, removing a `proxy` that is the first key of an
  item, multi-line scalars): (A, recommended) re-encode the whole base config with yaml.v3 (comments kept,
  blank lines/quoting normalised) after verification; (B) refuse as today (400, text kept).
