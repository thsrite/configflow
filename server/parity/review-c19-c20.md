# C19 / C20 adversarial review

Independent review of `backend/converters/surge.py` and `loon.py` against
`internal/convert/surge.go`, `loon.go`, and shared `clients.go` (formerly
`clients_py.go`). Public APIs and generated configuration semantics are kept.
Scope confirmed by the coordinator on 2026-11-17: functional findings block
verification; the existing package-wide dynamic types and Python exception model
are **S-convert debt, pending the N8 design**, not a reason to rewrite public APIs
in this review.

## Findings

| Severity | Finding | Resolution / evidence |
|---|---|---|
| Medium | Loon joined the remote source kind, resource ID and exclusion with `\x01`. A delimiter inside the ID/exclusion can alias a different source, including a cached missing source. | A Go struct key keeps the dimensions separate. Direct regression and Python-derived `remote-cache-delimiter` / `remote-cache-missing-source` config cases. Restoring delimiter concatenation on `.63` made the direct regression fail with `distinct sources/exclusions need two remotes`; fixed source restored afterwards. |
| High | Surge DEBUG logged the generated group line, exposing subscription URLs and the config token. Python has the same defect. | Log only that a group was generated. `TestSurgeDebugLogOmitsSubscriptionURLsAndTokens` exercises DEBUG logging and verifies that neither URLs nor tokens appear. Generated lines are unchanged. |
| Structural debt | Dynamic hashable maps, string/type/exception adapters and panic-based propagation mirror Python instead of Go. | Local strings/regexp/strconv operations and the remote map key now use Go libraries; emulated `len` and unused `nodesByID` exception probes removed. Remaining debt is enumerated below; no public API changed. |

No other functional differences found. No unresolved functional findings.

The sensitive log is Python `surge.py:1082` (`Group ... final line`) and the
corresponding old Go group-conversion log. It is emitted at **DEBUG** when a
successfully rendered group has subscription/aggregation policy paths during
Surge config generation. Fields include the effective base URL, profile ID,
subscription/aggregation IDs and endpoint paths, include/exclude filter queries,
and the URL-encoded `config_token` when nonempty; the line also includes member
names, test URL, interval and smart priority. Without a policy-path it still
contains member names/test options, but no config token from this code. Python
`logger.py` and `app.py` default to INFO, so this specific line is suppressed at
the default level; `LOG_LEVEL=DEBUG` enables it for both the file and console
handlers. Python was not changed and production logs were not accessed. The
coordinator received these trigger/field details separately to assess impact.

## Accepted differences and deferred structure

- Generated config semantics: no differences. Whitespace/quoting/line endings do
  not need byte identity; the current references also pass exact text checks.
- Surge debug log content deliberately omits sensitive rendered lines (Python
  bug fixed); log order/text is not part of generated configuration semantics.
- Go-native Unicode case/space behavior is accepted under PORTING's CPython-only
  Unicode rule (e.g. Python-only C0 whitespace). Production data and all retained
  valid references have no resulting difference.
- `clients.go`: `pyDict`/`newDict`, `truthy`/`or2`/`eq`, `joinAny`, legacy string
  receiver/type guards, `strIn`/`nextMatch`, `hasPortListAny`,
  `networkAsProtocolAny`, `rulesetFormatAny` (including the sentinel URL probe),
  and policy pre-scan remain **→ S-convert, waiting for N8 design**. Removing
  malformed-value guards independently could change rejection into success or
  change an internal failure into a user validation status.
- `surge.go` / `loon.go`: dynamic profile/node/group fields, hash-key probes,
  `dictGet`/`dictItem`/`iterate`/`fstr`, and `must`/`raise`/`catch` in exported
  generation/node/group/subscription wrappers remain **→ S-convert**. Their
  implementations also depend on `mihomo_generate_py.go`, `dialers.go` and
  `errors.go`; those shared package-wide layers are outside this local cleanup.
