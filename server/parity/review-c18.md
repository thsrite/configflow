# C18 adversarial review

Scope: Mihomo config generation and artifact download lists in
`backend/converters/mihomo.py`; Mihomo base-form validation, takeover mode and
Agent context in `backend/common/mihomo_base_settings.py`. Go implementations:
`mihomo_generate.go`, `mihomo_downloads.go`, `base_settings.go`, shared
`mihomo_generate_py.go` / `mihomo_generate_env.go` and existing collaborator APIs.
Public APIs stay unchanged. Existing dynamic document/exception emulation is
explicitly assigned to S-convert after the N8 design, per the coordinator.

## Findings

- **High:** YAML parser diagnostics include source excerpts. Both Python and Go
  copied the whole diagnostic into ERROR logs when custom base YAML was invalid,
  exposing secrets or credential-bearing URLs on the offending line. This is
  enabled even at the default INFO log threshold. Go now returns the same
  `CustomConfigYAMLError` without logging it twice. The original failure status,
  diagnostic to the caller, abort and absence of a generated output are kept.
  `TestMihomoReviewYAMLFailureLogOmitsConfiguration` failed on the original code
  for both a synthetic controller secret and a synthetic DNS URL with a token.
  Python was not changed; production logs were not accessed.
- **Medium:** an empty legacy library URL represented by false, zero, an empty
  list or an empty object was stringified into a nonempty source URL. That
  incorrectly forced text instead of inferring YAML from the rule's own fallback
  URL. Go now treats empty values as absent before formatting. Generation and
  ruleset downloads retain the same accepted inputs and produce the same format
  and extension as Python. `TestMihomoReviewEmptyLibraryURLUsesRuleFormat` failed
  for those four values before fixing; null/empty-string were already correct.
  Python independently confirmed all six variants yield `yaml` and
  `./ruleset/Rules.yaml`.

## Boundary acceptance and coverage matrix

`TestMihomoReviewBoundaryReferences` reads an independently authored synthetic
corpus generated by the real Python public entry points, not by a Go-derived
model. Expected YAML is parsed with Python; the Go public
`GenerateMihomoDocument` result is compared structurally (mapping order ignored,
ordered lists/rules preserved). Generation reports (including partial reports on failure) and changes to the
logical profile are also compared. Download lists retain order and all fields. Base-form
checks compare acceptance/rejection and exact Chinese validation messages.
Recorded replays and the existing randomized corpus remain additional checks.
Restoring the broken empty-URL stringification on the remote copy made these
structural config and download comparisons fail; the fixed source was restored
after the mutation check.

The corpus has **1010 rows, 235 expected rejections**: 158 config generations,
159 provider-download calls, 159 ruleset-download calls, 524 base-form validations,
6 takeover-mode calls and 4 Agent-context calls. Test references use synthetic
hosts, documentation addresses and made-up credentials only; built-in public
service constants and the GitHub origin identifier exercise product defaults and
the GitHub rewrite feature. No production snapshot values were copied to fixtures.

Production source tracing runs on a disposable snapshot copy in a network
namespace with only loopback; the source snapshot is bind-mounted read-only.
It prints only source/function/line identifiers and static counters. Observed:
`main=2`, `agent=1`, `subscription=4`, `download-pair=2`. No base-settings function
was called. The default template, MosDNS hosts parsing/sync, GitHub prefix rewrite
and no-resolve injection were also unvisited. Therefore production success counts

## Cache and log sweep

- C18 owns no delimiter-concatenated cache key. Subscription/cache callbacks take
  the source ID directly; C12's node-conversion record and YAML cache use the
  exact source string as their map key. Scope results and parsed cached objects
  are copied before applying outer names. No Loon-style tuple collision found.
- Proxy-provider mapping keys are the configured provider names, with the same
  last-value behavior as Python; this is not a multi-field cache encoding.
- Existing provider DEBUG URLs use `weburl.SafeForLog`, while the token log only
  reports whether configured. Node/group collection logs contain identifiers,
  not node bodies. The reproduced ERROR YAML-excerpt leak was fixed above.
- External collaborators' logs/caches stay in their owner modules. This review
  does not silently claim to re-review C11/C12/C13/C17/HR gateway internals.

## Local Go cleanup and deferred structure

- Bounded port/MTU/interval comparisons and sniff-port checks now use native
  int64 bounds instead of allocating arbitrary-precision comparison objects.
  Values outside int64 already exceed every allowed bound; huge-number and
  Unicode-digit rejection tests plus the original 6000 validation rows pass.
- DEBUG collection counts use `strconv.Itoa` instead of constructing JSON/Python
  numbers just to print a Go slice length.
- Validation string case/space/digit helpers were retained to avoid independently
  changing malformed-input acceptance or rejection. Complete native conversion
  belongs to S-convert/N3/N8 with the reviewed data-model design.
- **S-convert after N8:** `mihomo_generate_py.go` `raised`/`raise`/`catch`, dynamic
  dict/list/string/error adapters, ordered hashable sets, Python scalar/repr/int
  glue; dynamic generation/group/download fields in `mihomo_generate.go` and
  `mihomo_downloads.go`; `sourceURLText` for non-string legacy values;
  `base_settings.go` dynamic missing/type/same/port/IP adapters and panic-based
  BaseSettingsError propagation; `GenerateMihomoDocument`'s dump/reload adapter.
  Public APIs and invalid-input acceptance/rejection are deliberately retained.
- `controllerSecretError` remains the existing setup-flow helper copy until C36
  exports its owner function; semantics are checked at the public validator.
- Gateway/onboarding device behavior is outside C18: only hook ordering,
  invocation, supplied generated effects and failure propagation are checked.
  No physical networking, Docker, TUN or device operation was performed.

## Accepted differences

Generated structures, fields, values, rule/list order, reports, mutations and
validation messages match Python. Byte formatting is not an acceptance target.
The sensitive duplicate ERROR log is deliberately removed, fixing a Python bug.
Existing non-string YAML mapping-key rejection, JSON-inexpressible YAML values,
set/debug ordering and Agent ports beyond int64 retain their previously recorded
limits; none is newly introduced. No public API changes or new dependencies.
