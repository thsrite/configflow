## 设计对应与编辑判定

| 编辑类别 | 路径与条件 |
|---|---|
| 无变化 | 原字节返回，包括空文档、空白、BOM 和注释 |
| 标量值/标签修改 | 原地替换：Node 身份和位置/风格/注释元数据稳定；原 token 是单物理行 plain/单引号/双引号，新 token 也可编码成单行；无显式 tag/anchor，且没有外部 alias 使用该节点。flow 中的字符串强制引用以免分隔符歧义 |
| 删除整对 key/value | 原地替换：block map 的完整行范围可证明；键前只有缩进，不是 `- ` 后第一个键；不产生隐式空 map；不触及 flow 删除、共享 anchor、block/multiline scalar 或有歧义的边界。删除范围内的flow集合必须由原生Parse证明在单物理行内完整结束。独立注释/空行保持，行尾注释转为同缩进独立注释 |
| 新节点、换序、序列结构变化 | 整份重写 |
| 不满足以上安全条件 | 整份重写，包括 flow 删除、block/multiline scalar 修改、共享/继承 listeners、显式 tags/anchors 和不确定范围 |
| 输出失败或语义校验失败 | 返回原文及 ErrUnsafeEdit；调用方沿用原来的中文 400，仓库事务不提交 |

每个输出都重新 Parse 并与编辑后 Node 做 Equal。原地替换通过补丁范围证明原注释
字节保留，语义再校验；不要求 yaml.v3 后续仍把孤立注释附着在同样的 Node 上。
整份重写恢复被删除/替换节点遗留的注释，必要时放到文档头，逐条计数核对。
标量内部的 `#` 不算注释。输入统一 CRLF 时，原地替换和整份重写均保留 CRLF。
删除/替换 anchor 定义后，其未被编辑的 alias 使用者物化为原值，避免悬空引用。

D1：新增 ErrDuplicateKey，由 SyntaxError 包装，errors.Is 同时识别 ErrSyntax；
errors.As 可取得 DuplicateKeyError.Key/Line。subs 的解析失败在原中文上下文后
追加原生诊断，其余校验消息不变，集中在 messages.go。源码和事务失败原子性有测试。
D3：无法证明原地修改安全时整份重写，保留注释，统一空行和引号样式。

协调者批准的 N7-1 共享 API 修正，已写入设计 2.2 和 behaviour-changes.md：
- Marshal 的 prepareStrings 将 FoldedStyle 统一为 LiteralStyle，按实际字符串值输出，
  避免 yaml.v3 对更深缩进续行多加 LF；覆盖 hash、缩进和 `-`/`+` chomping 变体。
- 非标量（sequence/mapping）键的 LineComment 移到该 pair 的 HeadComment，避免
  yaml.v3 输出 `[] #\n: null` 这类无法再次解析的文本；标量键位置不变。
  失败种子 98ed6062 保留；已有 FuzzNativeRoundTrip 加入对应种子，严格验证
