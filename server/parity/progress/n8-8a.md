## N8-9 prerequisite — shared rulesetfmt

提前提供 `RuleFormat(model.RuleConfig, []model.RuleLibraryItem, string)`，唯一格式判断实现。
旧 Format 仅转码、转错误类别；N8-9 迁移 rules/rulefetch 等剩余调用方后删除适配。
正常语料对照 Python 原夹具与两种入口的格式字节；旧 golden 不改。
协调者确认：畸形 URL、非字符串 ID/name、非 object library 项按 R5 或明确类型校验，
不重建 truthiness/动态 ID 相等。整份 library 在适配边界解码，因此匹配项后的非 object 也拒绝。
`URL=5` 继续保留 URLTypeError 类别；convert 的中文上下文留在调用方。
