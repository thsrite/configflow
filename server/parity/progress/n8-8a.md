## Dialers — typed resources, filtering and topology

`dialers.go` / `dialers_api.go` 只使用 model.Config、model.Node、model.ProxyGroup、
yamlx.Node 和 typed DTO。ConfigShapes、ConfigDialers、BuildDialerGraph、NodeDialer、
NodeDialerTarget、GroupRefs、GroupSources、IncomingRefs、ResolveNodeDialer、ApplyNodeDialer、
RequiredNodes、RejectUnsupportedDialers 为资源入口；FilterSpec / NameOverride / TopologyOptions
负责 Provider 过滤、命名和 ValidateTopology。依赖图保持发现顺序，重复 ID 只覆盖值，
迭代 DFS 拒绝循环，Group 的 provider ID 排序仍为字符串序。没有动态 ID 相等或 Python 异常模型。

所有旧入口只在 legacy.go 转码，DialerReferenceError 的旧调用方判别及原生 cause 链保留；
已有 ProxyYAMLError 直接穿过，冻结 YAML policy oracle 的类别和行号不变。
resource-array codec 只做非 null object-array 的类型解码；成员/引用/业务校验只在 typed 核心。
ConfigShapes 用 record 当前编码证据验证成员形状，区分缺失与显式 null，并支持修复后的值。
Provider override 的 key 精确区分大小写，直接从 Node 读入 typed 规则，不使用 JSON struct 的宽松大小写匹配。
名字过滤维持 backtick 顺序、原名去重、排除类型、正则替换和链私有名字冲突校验。
非 ASCII ordinal 两条 review + 八条 helper 差异经协调者批准为 native literal，独立断言；旧 golden 不改。

AST 覆盖六个核心文件：禁止 jsonx/pystr/any/动态异常及 legacy 反向调用。
`hashID` 仅为未迁 (b)/(c) 生成器移到既有 pyhelpers.go，a 核心不调用；这些调用方迁完后删除。
N8-5c 可改用 ConfigShapes(*model.Config,bool)、ConfigDialers(*model.Config)、
NodeDialer(model.Node)(*yamlx.Node,error)；本分支不依赖 PublishConfig 或 (c) API。
