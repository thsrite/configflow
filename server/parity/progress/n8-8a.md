## common — typed core

`common.go` 只读 `*model.Config` / `model.RuleConfig`：FallbackPolicy、DirectNTP、
BuiltinNTPRule、RulesForOutput、RuleComment、RuleFormat；纯文本入口继续使用原签名。
薄转码入口在 legacy.go。旧调用方仍需要的 contains/iterList/asObject/regex/splitlines 等
辅助函数暂放既有 pyhelpers.go，核心不引用它们，后续 (b)/(c) 删除。
AST 锁定核心无 jsonx/any/动态异常/legacy 反向引用，并锁定旧入口只调用 typed 入口和转码函数。
中文 AfterMatchNote 移入 messages.go。

正常输入按原字节比较。畸形语料不再作为 Python 内部动态语义 oracle；先按字段类型/形状明确分类，
独立测试锁定 R5 或显式错误，旧 golden 不改。原 37577 行 helper corpus 中 859 行有迁移字段的
畸形类型：rule_configs array 21/object 3/content 20/enabled 128/library_rule_id 37/name 164/
ntp_direct 108/policy 85/udp_fallback 112/url 8/value 119；rule_library content 15/format 20/url 19。
分类取第一个不合类型的字段，互斥计数；其余行仍直接比较。
非 object library 经 model.Shared 的 R5 读为空列表，包含匹配项前/后两类回归。
非字符串 URL 仍明确返回 ErrURLType，四种空假值在 Mihomo 真实生成边界明确断言拒绝；
对应旧 review 行由此独立回归替代。无任何业务 truthiness 或动态 ID 相等实现。

协调者补充裁定：5 行尾部 U+001C/U+001D 使用 Unicode whitespace native 期望；
10 条一对多大写用已有 x/text/cases 保持结果，逐条测试。

## Node conversion — typed graph boundary

`NodeProxy(context.Context, model.Node, NodeConverter)`、`StructuredProxy`、`FixProxyNode`、
`GitHubURL`、整数端口集合和 `Conversions` 已迁到 typed records / yamlx.Node。
JSON 输入先走 encoding/json 语义，YAML 沿物理图投影键，保留 alias 共享和统一预算。
缓存只保留不可变 YAML 字节，命中返回独立节点；alias 图不入缓存。
旧公开入口在 legacy.go 转码，核心不调用 legacy。未迁的 generator 所需 reader 转码暂留在该文件。
畸形名字、端口等用 R5；params 非 mapping、结构化 type 非字符串返回明确验证错误。
端口收集不重建 Python 数值哈希或集合顺序，只保留有效整数端口和准确 owner。
NaN/Infinity 非法 JSON 交给原生 YAML 路径，逐词断言其字符串语义，旧 golden 不改。

Python 浅拷贝曾给输入 Params 加上 short-id。typed 输出继续补齐 short-id，但输入原文不变。
独立 `n88_input_patches.json` 精确列出 31 行和路径，只修改这些路径的新期望；
所有其余 mutated-profile 字段仍严格比较。夹具生产器只读取冻结输入和 Python oracle，
不调用转换业务。普通单测和 FuzzTypedNodeProxy 均锁定 Params 原文不变。
