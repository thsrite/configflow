## 调用点与设计对应

| 调用点 | 新 API / 边界 |
|---|---|
| subs/parser.go ParseURIList YAML 数组、ParseYAMLObject fallback | Parse → ProjectJSONKeys(RejectNonStringKeys) → ToJSON → jsonx.Parse |
| subs/compat.go parseStructuredProxyString YAML fallback | 同 parser；合法 JSON 先走共享 FromJSON/encoding-json，URI 分支不变 |
| subs/dialers.go ExtractSubscriptionDialers | Parse → ProjectJSONKeys(DiscardNonStringKeys) → ToJSON → jsonx.Parse；删除 LoadCSafeFirst、私有 stringKeysOnly |
| subs/hosts.go ExtractSubscriptionHosts | Parse → AllPairs，保留标量键的原始 tag 供原业务校验；每个值 ToJSON 后 jsonx.Parse |
| substore/client.go isYAMLResponse | 原有快速字符串探测边界不变，剩余 Parse/Get；删除 Compose fallback |
| substore/client.go ParseProxiesFromYAML | Parse → ProjectJSONKeys(StringifyScalarKeys) → ToJSON → jsonx.Parse；删除 Mapping/Lookup/jsonKeys |

三种键模式只有 yamlx 一份实现，类型化常量：parser 拒绝非字符串，dialers 丢弃，
substore/provider 转换 number/bool/null 为 JSON 名，其他类型拒绝；转换碰撞最后值生效，
保持第一次出现的位置。先在原图规划全部物理 mapping，成功后统一写回，避免先转换 anchor
改变后续 merge 的 typed-key 优先级；失败原图不变。独立 yamlx 单测锁规则、merge、碰撞、非有限键、alias 共享、D1。
Hosts 的 ProjectHostsYAMLKeys 仅验证业务保留的 scalar 键和值预算，不做另一份键转换。
这是 N8 移除 jsonx 前的过渡层，由 N8-9 S-subs/substore 删除。

HANDOFF 3d：所有 YAML→jsonx 路径先检查完整图，物理图投影保留 alias 指针共享，
ToJSON 再检查输出子图预算。40 层二叉共享 alias 与自引用在每个上述入口回归；
parser 返回原来的 nil/empty，hosts 返回 parse_error，dialers/substore 返回明确中文错误。
探测器仅返回 bool、不展开，后续 parser 仍拒绝。另测大文档稀释预算后子树单独超限：
返回 ErrAliasBudget，绝不静默填 null。无用户文档运行时 Clone。

## 迁移门与 oracle

1. Python collect 仅包装 yaml.load/safe_load，记录真实 Python 业务调用的原始 source/mode。
2. Go 生成器只调用 Parse、生产唯一键投影函数、ToJSON；不调用 Go 业务函数。
   每条先保存完整 Parse 物理图（tag/value/line/column/content/alias ID），再保存注入值。
3. Python replay 只替换 YAML loader，真实业务代码不改、不 patch 其他函数；期望来自它。
4. 逐输入旧 API 与新 API 对照、分类；每个 expected 变化追溯到 old/native loader ID。
   经授权扩大 convert/TestSurgeLoonCorpus 接入（不改 convert 产品代码）；其原隔离
   corpus 环境不变，不新增任何非 YAML patch。collect 先严格比对全部 34697 行旧 golden。
   unchanged convert 只存调用 manifest，继续直接使用原 golden；changed 则存完整 Python
   输出（含配置全文、mutation、错误）。YAML 行的 mutation 用结构比较，键顺序无意义，
   数组顺序/所有字段/数字精度/类型仍严格；生成配置字节完整比较。
   非 YAML 原 golden 继续严格比较；JSON 比较不忽略字段、不混淆 bool/number/null/empty。
5. 两份 fixture 分开保存：n7_native_values.json.gz（先记录），n7_reader_expected.json.gz。
   core 语料无业务注入，用无损 flat graph audit，避免深层 JSON wire 遇 Python 递归上限。
