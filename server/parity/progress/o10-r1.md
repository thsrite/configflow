# O10-R1 S1-Agent：Agent 读 API 借用不可变快照（2026-11-21）

分支 `go-perf-r1`，基于 `go@0c009f67e`（原基点 batch-21 `ea38617a0`，相对 go 只多测试/文档提交，已 rebase）。

## 状态

完成。读 API 默认借用；guard 测试期默认开；race/门禁/负向对照到位；性能实测见下。

## 做法

- `repo.BorrowAgents(ctx) (records, shared, err)`：返回 store head 缓存（或 WithReadSnapshot 固定代）的注册表切片，不拷贝。
  写事务内返回工作副本，`shared=false`。`ViewAgents` 改为经它取数。
- `agents.Manager` 的 `ReadAgent`/`ReadAgents`/`ListAgents`/`AgentSnapshots`/`ReadHAPair`/`AgentPair`/`ReadAgentByToken`：
  返回**新切片 + 每条记录的结构体浅拷贝**（`history=false` 时在浅拷贝上 `Clear` 历史，COW）；心跳 overlay 改的是浅拷贝。
  因而调用方可以改顶层字段、给自己的切片下标赋值；不能经指针、Map 值、嵌套切片改。事务内仍 `copyAgent` 深拷贝。
  语义写在 `registry.go` 的 “Borrowed records” 注释里。
- `agents.CloneAgent`：显式深拷贝（名字写明代价）。`copyAgent` 只剩 `readerAgent`（事务路径）和写结果（`setAgentSwitch`、`DeleteAgent`）。

## 安全网

- **guard 默认开**：`repo.Open` 在测试二进制（`testing.Testing()`）里装 `defaultViewGuard`（记日志含首个差异位置 + 栈，然后 panic
  `repo.ErrSnapshotMutated`）；生产无 guard。借用 API 每次借出都校验该代编码（首借记录，后借比较；新代入表时校验并淘汰旧代，最多 8 代），
  `View`/`ViewAgents` 原有回调前后比较保留。`SetViewGuard(nil)` 供分配测试关闭，`CheckBorrowed()` 供测试末尾检查保留的借用。
- **guard 实测抓到 1 处真实违约**（若无 guard 就是静默错误）：`dnsha` HA 发布状态机 `advance`/`ActivatePair` 原地改读到的
  `OxiDNSHAPublication`（`active_agent_id` 等）再保存。修复：进入状态机前 `ownJournal` 只深拷贝 journal（发布期才走，不在空闲路径）。
- race 测试 `TestBorrowedReadsSurviveConcurrentCommits`：8 个读 API × 4 个并发读者（借用后编码两次比较）+ 1 个写者循环 25 次提交
  （顶层标量、嵌套指针 `oxidns_ha.role`、Map 条目）并观察心跳；写者断言提交前借到的结果编码不变；末尾 `CheckBorrowed`。
- `TestBorrowedReadsAreCallerShallowCopies`：顶层改写、`SetJSON`、切片下标赋值不回流到快照。
- 负向对照 `TestViewGuardCatchesBorrowedMutation`：改嵌套指针、指针标量、Map 值里的指针、嵌套切片元素四种，guard 都触发、
  `CheckBorrowed` 返回 `ErrSnapshotMutated`；默认 guard 确实 panic。
- 源码门禁 `TestAgentDeepCopyBoundary`（AST）：全仓非测试代码中 `copyAgent`/`CloneAgent` 只允许 4 个带理由的 file:function，
  `internal/api/**`、后台循环一律禁止；过期豁免报错；自测用例覆盖 handler、循环、私有拷贝与借用读。
- 分配测试（9 个包的 O10/N89/N811 用例）在测量前 `SetViewGuard(nil)`；两个负向对照原来用 `ListAgents(true)`/`AgentSnapshots(true)`
  当“全量拷贝”，借用后它们不再随历史增长（正是收益），改为显式 `CloneAgent` 做对照，并新增断言借用列表不随历史增长。
