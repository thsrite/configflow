# O18 T1d — model 包外的记录改普通结构体，删除旧 R5 机制（2026-11-23）

分支 `go-o18-t1d`（基于 go@a2a92eca2，T1a/T1b/T1c 已合入）。沿用 T1a–T1c 裁定：宽松读存储（错类型 → 零值 + issue）、严格输入、
未知成员丢弃（DATA_DIR 文件告警或静默，见下）、开关错类型按真值（设备写入/门控类 `stored:"gate"` 读作关）、安全相关失败即关。

## 做了什么

### model 包
- 删除 `record.go`（DecodeRecord/EncodeRecord/SetMemberJSON/ClearMember/Raw/valueIssues/storedType）、`map.go`（Map）、`member.go`（Raw.MemberJSON）、
  `fields.go`（保原片段的 Fields）、`json.go`（parseObject/splitArray/objectJSON 原片段机制）、`switch.go`、`content.go`；`issues.go` 去掉 `Issues()`。
- 新 `encode.go`：只保留普通记录需要的编码器（Marshal/encodeUnit/环检测/深度检查/validJSON/scalarJSON/validUTF8），没有 MarshalJSON 的结构体
  按成员写出（声明顺序、omitzero），供 model 包外的普通记录直接用；OrderedMap 参与环检测（自引用以前会栈溢出）。
- 新 `object.go`：`Fields` 是不保原片段的普通有序对象（成员值原样、写时复制），给设备回复透传、探测结果、逐成员读取用。
- 新 `truth.go`：`Truthy`（取代 JSONHasContent）、`Switch`（取代 JSONSwitchEnabled）、`Flag`。
- `DecodeLenient[W]`：model 包外记录的宽松 UnmarshalJSON（对象 → wire 类型）。`DecodeDocument` 去掉恒为空的 issues 返回值。
- `_revision` 改 `int64`；严格输入的顶层 int64 仍接受 `60.0`/`6e1`（不接受文本）。

### model 包外（C3）
- notifications：Item/Navigation/RouterCheck/RouteHints/RouterReport/RouterSummary；`Items = model.OrderedMap[*Item]`；
  报告视图保留原始报告（发布摘要读未声明成员）；文件形状错误照旧拒绝。
- health/check：TimedRecord = 有序对象（checked_at 访问器）；PathStats/Suggestion/HostProbe/TargetState 普通结构体；
  probe/region 文件不保留未声明的顶层成员；区域文件条目非对象时 UpdateData 失败即关（文件不改写）。
- health：LatencyEntry 普通结构体（测试设置可选指针，测速组件的 first_latency 声明），损坏的测试设置不续接历史。
- substore：Cache/CacheMetadata/Traffic、release payload、runtime state；`Cache.Issues` + `NodesDamaged()` 给发布/汇总/provider 用。
- subs：HostsData/DialersData/DialerTarget（设置按订阅原标量存）、CoreAgent/CoreStatus、SourceMetadata（hostsDamaged、DialersStored）、chain/vmess/dns 视图。
- refresh：Traffic/SourceMetadata/NodeCache（MetadataDamaged/UpdatedAtDamaged 来自缓存 issues）、HealthEntry/FetchEvent、TransportReceipt。
- taskstatus.Receipt、setup.Record/Selections、api/stats 历史文件、convert 客户端选项、routersplit 视图、mosdns/oxidns 投影、ipv6 部署映射。
- 删掉调用方在普通记录上不可达的 `model.Issues` 分支；仍有意义的改为用解码 issues（Agent 注册表行告警、节点测速 DNS 设置拒绝损坏的 system_config、
  订阅缓存节点列表、Sub-Store 发布信息字段、链式代理过滤字段、vmess 端口）。

## 成员表（写出规则）
- 始终写：通知 Navigation 三个成员；订阅缓存 `subscription_id/updated_at/count/nodes`、metadata 的 `subscription_name/url/fetched_at`（后两者可为 null）；
  hosts 全部成员、dialer target 的 `type/members`、dialers 两个成员；健康历史 `history`、事件三个成员；区域文件 `services/domains/websites`；
