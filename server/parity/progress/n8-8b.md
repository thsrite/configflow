## Generator and output boundary

The generator now consumes model.Config, NodeConverter and typed options/reports.
It builds yamlx.Nodes and returns plain validation errors with the original domain
error categories where public callers inspect them. The custom YAML input uses
Parse -> RejectNonStringKeys -> the shared physical scalar projection, retaining
sharing without JSON whole-document expansion. Presentation flattens effective
merges, assigns stable automatic anchors, and strips old comments/style just as
the former generated JSON graph did. There is no runtime Parse/Equal pass.

Preflight receives the original logical values and the completed output graph.
Its test now compares all original fields instead of pointer identity: transcoding
creates independent DTOs. Region probe, provider/ruleset URL query escaping,
health-check defaults, followed groups and ordered engine options remain native
business decisions. Download results have string fields, malformed URL/path
values fail validation. Production Wire installs a typed environment; its test
checks every callback, including conditional cache/converter/preflight fields.

The unchanged byte gate passed all4548 frozen hashes: Mihomo2353, Loon1064,
