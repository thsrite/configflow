paused incremental IDs and zero NAT/filter writes; post-preview collision/order/ID/ownership drift;

bypasses yamlx nor catches an alias/policy failure as syntax. R10 must keep D1/alias-budget/ErrSyntax-only fallback
when integrating its own configuration parsing.

submitted DNS port, actual fake-device address table) and requires the real Python boundary comparison to
fail. TestR09BoundaryComparisonDetectsMutations additionally checks that each comparator dimension is observed.

## Differences / findings

- Medium Python safety defect fixed: after preview, a new reserved-name foreign object or a newly earlier
  port53 rule could pass Python apply's kept-row test; Go refuses before any write (fresh preview required).
- Medium Python safety defect fixed: Python rebuilds DELETE's expected proof from an immediately fresh row and
  refreshes manifest configs at the end without comparing the recorded image. An intervening edit could be
  deleted or absorbed into ownership. Go compares previous/create proofs again; edited rows are preserved.
- Low Python defect fixed: rollback remap keyed only by ID can cross table-local RouterOS IDs; Go keys by path+ID.
- Low malformed-record correction: missing/duplicate role/path/ID/config fails closed instead of Python crashes
  or missing-identity matches. Unknown stored manifest fields survive rollback refresh.
- Low resource-bound correction: cyclic/deep interface includes stop at 12 levels/256 visits (Python has no
  expansion bound). Rule-chain branch/jump bounds remain Python's 256/12. Unknown yields no drop assertion. Empty/wrong-typed actions and malformed interface-list includes also remain unknown, rather than taking a default allow/empty list.
- Formatting only: compact native JSON wire body vs requests spaces/key order (semantically equal); exact raw
  expectations separately asserted. Password diagnostics use shared redaction as already approved in R06/R07.
