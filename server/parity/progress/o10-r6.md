## 改动

1. **凭据集合按代缓存**（`repo/config_credentials.go`，`redact.ConfigCredentials`/`ConfigWithCredentials`/`ProfileWithCredentials`）。
   `public()` 原来每次把整份解析后的配置（`ConfigWithOxiDNSAgents`）编码再用 `CollectCredentials` 通用解码遍历。
   `CollectCredentials` 只收集模式下发现的值与 seeds 无关，所以
   `CollectCredentials(view, seeds) == NewSecrets(seeds, discovered(view), 注册密钥)`；`discovered(view)` 只依赖该代文档和配置空间，
   由 repo 按（不可变快照文档的 weak 指针, 配置空间）记住，与 `AgentRecordCredentials` 同一做法。写事务/section updater 内从工作副本现算、不缓存。
   不是结果缓存：响应仍每次构建、每次脱敏，只记住凭据集合。
2. **`ManagementService.Records`** 返回 `ConfigView{Routers, Credentials}`：借用的已存配置空间 + 记住的凭据，缓存命中时不做 `resolveConfig`
   （原来每次都水合 ruleset，占列表路由 70% 分配）。路由器只编码 `routers` 成员（与它在整份配置编码里的字节相同）再走原 R5 解码。
   报告/计划/policy-settings 需要整份配置的，用 `ConfigRecords`（同一次借用里拿解析视图 + 凭据，保证同代）；`inspect` 需要 JSON 时才 `Encoded()`。
   `safeText`（写路径日志脱敏）同样用记住的凭据。
3. **policy-settings**：`ReadWorkspace(*model.Config, …)` 用 `oxidns.NewTypedProfile`（生成器、`api/oxidns` 已对解析视图这样用），
   不再 `json.Marshal(config)` → `ProfileFromJSON` 再挑字段解码；ruleset 行直接读类型化字段，若 `rule_configs` 下有解码 issue（类型错误，原字节保留）
   则退回原来的严格解码，错误不变。OxiDNS settings revision 只算一次（原来算两次）。
4. **upstream-routers**：`allProfileSecrets` 用 `View` 列配置空间 id（不再走 `ListProfileRecords` → `agentBindingRecords` → 整个 System 编码），
   每个配置空间用记住的凭据。原来用不带 Agent 投影的 `Config`，现在用带 OxiDNS Agent 投影的那份：投影是存储 Agent 记录的成员子集，
   其凭据已被随后的 `AgentRecordCredentials` 全部加入，并集不变。`pendingTargets` 先用借用的已存配置空间判断有没有路由器链接这个 Agent，
   没有的配置空间不再解析+编码整份配置（加载时每个配置空间都已解析校验过，跳过不会吞掉错误）。
5. **`ManagerAgentSource.Agent`**（路由器检查/规则同步读网关 Agent）：原来对借用记录 `json.Marshal` 后再解码成 `model.Agent` 和 `DNSAgent` 两份；
   现在 `model.Agent` 视图是借用记录的浅拷贝（同 R1 约定：顶层之下只读），`DNSAgent` 只从它读的 7 个成员组装后用同一个严格解码器解码（错误相同）。

## 未做（理由）

- `lockedFor`/`releaseRouterRecord`/`jsonEqual`（policy 路由剩余分配大头）：是发布 CAS 的“记录未变”证明，属路由器写路径语义，延迟已远低于 Python，不动。
- `Inspect` 内部把配置 JSON 再解码成 `model.Profile`（upstream-routers 在设备不可达时每次都跑检查）：改成类型化要动 `InspectRequest` 和
  IPv6 检查的输入，解码后的 profile 含配置顶层成员，不是逐字节等价，风险大于收益（upstream 已 3 ms，Python 13–34 ms）。
- `oxidns.NewTypedProfile` 的 `groupNode`（policy-settings 剩余 17%）：oxidns 公共构造，影响生成器，留给 R5/S3。
