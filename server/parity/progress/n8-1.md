## Contract and implementation

- Design §2.6 / N8-1: `7f1a86e4` adds ordered encoding/json MarshalJSON and
  UnmarshalJSON bridges for jsonx.Object / Number, retaining literal numbers,
  duplicate last-value/first-position semantics and native mixed values.
  Cycles fail; shared object/slice prefixes remain valid.
- `fddd26f7` unifies JSON/JSONStatus/Message/External/RawJSON and JSON error
  bodies in writeJSON: native encode → decoded-token redaction → sorted UTF-8
  output. Existing passthrough files/streams and endpoint exemptions remain.
  External no longer pre-redacts or uses a marker/plain-tree bypass. localhttp,
  Invoke and httpxtest use native encoding.
- Coordinator clarification: pending Go values visit original keys sorted before
  redacted-key collision resolution; RawJSON visits input order. Last value
  wins; final output sorts. Materializing/reassigning Body in a hook preserves
  that provider order (`eade3742`). Final committed secrets are read after hooks.
- `7a50c671`: coordinator-approved Python bug fix: every ordinary JSON response
  writes NaN/±Infinity as null, including native floats, legacy numbers and raw
  bodies. Only a failed native encoding needs value repair; caller data is not
  modified. Native JSON tags/embedding, bytes and custom scalar encodings stay.
  Raw repair recognizes only those numeric literals outside strings; all other
  malformed syntax still follows the existing silent-parse behaviour.
- Non-HTTP bridge/storage encoders do not change. A04/A05 ingestion follow-up
  (reject/drop non-finite points before storing) is recorded in PROGRESS-agents;
  this step does not implement it. See behaviour-changes.md.
- Design §2.7 / D2=B: no canonjson. Appendix A inventories 85 production/helper
  encoder calls and 134 test-only calls in 79 files, pinned to `7f1a86e4`.
  Six HTTP/request/helper sites migrated; persisted identities stay unchanged
  until their consumer steps. Python-derived goldens freeze notification
  fingerprints, router signatures, remote-rule cache paths and hosts digests.
- `9da4cb8b` adds the response-writer audit. `edc74c2a` covers nil members during
  non-finite repair and shared slice prefixes. `817f66bc` asserts panel non-finite
  fixture fields and allows accepted JSON formatting in HEAD error responses.
