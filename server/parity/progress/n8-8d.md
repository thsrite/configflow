## 实现与接线

- provider 主体 delivery/response/errors/hooks 直接消费 model/typed DTO/Node；四文件无
  jsonx、pystr、any、PythonClass、pyError、私有标量解码或 Uninterruptible。
  删除 util.go 的 pyIter/hashable/containsEqual。Error 保留真实 typed domain cause，
  FieldPath/FieldStep 表达来源位置；内部错型使用 InputError/native URL error。
- DeliverySnapshot 冻结一张只读 main 图与 chain name 索引，Validate 只拥有修改的根容器，
  不按 provider 或节点重解 main/Config。Artifact/CacheWrite、DeliveryOptions、
  DeliveryEnv、AggregationRenderer 是 native API。旧消费者的纯转码入口集中 legacy.go，
  旧 Snapshot 以 sync.Once 解码；N8-10/11 消费者完成后才能删这层。
- mihomoenv 的生产 Preflight 直接接 PrepareBundle。聚合 Wire 接 typed renderer，HTTP dry
  render 与嵌套 bundle 共用 typed delivery；删除旧的逐节点 OverlayDialer/config 与
  AdaptSubscriptionProxies/main 转码链。每批源读取、节点转换记录、机场 dialer 记录和
  unknown model 字段继续由各自 owner 维护。缓存 enabled/subscription_id 回写保留。
- 将可选节点转换的既有策略集中到 convert.OptionalNodeConverter：普通转换失败跳过节点，
  原始 Runtime shutdown 仍传播；provider、聚合、mihomoenv 共用，未改生成算法。
- DNS exports 使用 AppendQuery 的 ordered string pairs、RuleLines、RuleLiteral、
  netip/netipx。保留规则编辑器换行与 portable regex grammar、IPv4 netmask/hostmask、
  scoped IPv6。删除旧 AppendURLQuery/PySplitlines/PyReEscape 产品出口及私有 URL 动态参数
  helper；旧 HTTP fixture 仅在测试入口投影退休的动态 query 参数，原行与期望未改。
- Provider 路径解析仍复用 weburl.Parse，保留 stray percent、userinfo 和 zone 的共享兼容。
  外部订阅解码、Base64、机场 group type 白名单继续使用 subs/substore owner，没有复制解码器。
