## 实现

- subscriptions 的 Shared/UpdateShared/Config、订阅筛选、刷新/健康记录、缓存、provider bundle/serve、节点转换与排序改调 typed owner。相同 PUT 保留原行字节；暂存节点的库 ID 与上游协议 `id` 分开。
- aggregations API 与生成 adapter 改调 model/native provider、转换、排序与缓存入口。保留对外 `Generate(json.RawMessage, json.RawMessage, Options)`；新增 `GenerateConfig` 供 typed 调用，不改 render 业务与输出。
- nodes 的 CRUD、行解析、探测、DNS 改 native owner；删除 planner 保留旧实现等待 W1。
- handlers 使用 Bind/BindSilent；非有限 JSON 数字在副作用前拒绝。普通畸形输入保留各路由原有状态和 silent 策略；非 JSON MIME 的原策略保留。
- auth 最终入口为 `ValidateSystemTokenOrJWT(c, *model.System)`；旧 `ValidateTokenOrJWT` 只做薄转码。不得将 W5 的两个捕获快照调用改成 nil。
- health 默认 collaborators 直接调用 typed subs/substore、ReadSharedBytes/WriteSharedText；删除产品 `health/legacy.go`。`ConvertNodeForProbe` 只转调原 typed 转换 owner，供注入 URI converter 使用，不复制探测转换逻辑。
- refresh 默认 SourceOwners 直接接 typed fetch、节点/metadata/cache owner；删除 env_legacy.go、rows_legacy.go。共享文件使用 ReadSharedBytes 和标准 JSON；写入保留缩进/尾换行，复用 WriteSharedText。错误判别改 ErrorClass。
- subs/substore/provider 删除已无产品调用的旧入口；原回放的机械适配放在已有 `_test.go` 中，继续调用 native owner。删除 subs/legacy_references.go。health/check 仅删无调用的 InitializeProviderHealth，保留未合入并行包仍用的入口。

冻结 testdata/pyref 未改，没有删除已有测试覆盖；旧夹具所需的装配/返回形状在测试内适配，不把这些兼容逻辑加入生产 API。

W3 要求的 provider 投递与 token 校验 Opus 抽查尚未完成，不标记 verified。没有新依赖、新 fuzz target 或 Python 仿真实现。

并发四条常设项：测试未替换所测生产 timeout；探测 worker 继续断言原始 stdin JSON/命令，provider 继续投递字节比较；直接调用者测试已跑，最终合并树由协调者再验；新增真实 Runtime.Start/BindRequest/Shutdown 回归覆盖订阅写入口，断连可完成、shutdown 不提交。修复聚合/认证预读在 Detach 前读取取消 ctx 的入场退化。
