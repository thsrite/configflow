## Completed package steps

- version: typed Information response; encoding/json test.
- utilx: string/bool validation without JSON conversion.
- logx: fmt.Sprint fallback; native Unicode graphic/whitespace categories reject
  invisible characters and line separators. Generic nil diagnostic is `<nil>`;
  it used to be Python's `None`. No API or stored value changes.
- localhttp: native `%q` error quoting. Request body already uses jsonresp.Encode.
- auth: native JWT codec, exact received segments authenticated before Claims
  decoding; registered RawMessage fields plus opaque extension members. Expiration
  remains optional; fractional numeric dates remain accepted and truncated for
  comparison. Unknown fields preserved. Config-token repository adapter remains
  in legacy.go TODO(N8-5). No runtime jsonx in JWT/middleware.
  Original 26-case Python fixture unchanged (its junk_chars token already fails
  padding in Python); separate live Python evidence proves signature junk can be
  accepted there and is rejected natively. Native syntax detail text replaces
  Python parser internals; status and Chinese context unchanged.
  Tests: live bidirectional PyJWT, original-signature negative control, unknown
  claims, no-exp, algorithm allowlist, optional padding and Unicode.
