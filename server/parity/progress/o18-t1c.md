# O18 T1c — 路由器、设置、资源、策略记录改普通结构体（2026-11-22）

分支 `go-o18-t1c`，叠在 `go-o18-t1b` 上（协调者裁定合入顺序 T1b → T1c）。

## 已做（代码）
- model：`routers.go`、`routerownership.go`、`routerrulesync.go`、`resources.go`、`policies.go`、`system.go`、`settings.go`
  全部记录去掉 Raw/Fields/MemberJSON，成为普通结构体；编解码样板集中在 `plain_t1c.go`（plainRecord、plainWire、
  宽松 UnmarshalJSON、marshalPlain，部分记录保留 SetJSON/Clear）。`DeviceNotes`/`ClientFixedIPs` 与
  `DomainDiscovery` 的两个映射改用 T1b 的 `OrderedMap`。`MosDNSMatch` 仍自解码（字符串是合法形态）。
- MihomoSettings 声明原先放在 Fields 里的 `router_split`、`linux_gateway`、`linux_gateway_restore_point`（Dynamic）。
  ProxyGroup 声明生成期成员 `_chain_dialer`（ResourceRef）、`_chain_original_candidates`（Dynamic），Node 声明 `_proxy_chain_id`。
  RuleLibraryItem 声明 `policy`/`target`（RawMessage），只为让写入校验按 Python 文案拒绝。
- 严格输入（`plain_switch.go`）：嵌套普通记录作为输入时经 wire 视图逐成员严格解码（Q2-A）；`*bool` 给 null 读作关
  （`switch:"on"` 读作开）；`Int` 只收整数字面量；`input:"strict"` 的健康检查成员拒 null；`ProxyChain`、
  `ProviderHealthCheck` 拒绝未声明成员（Python：代理链必须恰为 entry/exit + type/id；健康检查包含未知字段）。
- `repo/input_errors.go`：严格解码失败时对被拒输入按 Python 校验顺序跑形状检查（groupShapeMessage /
  ruleShapeMessage / sharedShapeMessage / system_config 默认配置 ID），保持中文文案；新文案常量在 `messages.go`。
- 开关：`switch:"off"`（manage_return_routing、auto_rule_sync、dns_guard.enabled、ipv6_pd_guard.enabled、
  domain_discovery.auto_apply、backup.auto_backup）错类型读作关；`switch:"on"`（verify_tls）错类型或 null 读作开。
- 凭据：`config_token` 标 `text:"strict"`，库里存数字等非文本 → 空 + 告警，`SystemSettingsDamaged` 认这一条（失败即关）；
  `auth`、`setup` 不再读原值。
- 路由器所有权清单（ros_policy/dns_guard/ipv6_fakeip/ipv6_routes/ipv6_pd_guard state）：成员全部 omitzero（`{}` 仍是 `{}`）；
  库里错类型或带未声明成员的清单整份保留（`Stored`，`damagedKeeper`），守卫仍按 Python 真值判断（失败即关）。
- `repo.keepUnchangedRows`：行的「存在」也按值是否改变保留——记录省略但库里有的已声明成员行、以及库里没有而
  值未变的成员不新增行（避免首次写入增删空节/空文本行）。未声明成员行仍删除。
- 记录 null 当记录（非指针）→ 零值 + 告警（`system_config: null` 继续算损坏设置）。
- `routers.Router.MarshalJSON`：Extra 只保留已声明的设备状态成员；未声明成员丢弃。
