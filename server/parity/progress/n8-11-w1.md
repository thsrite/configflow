## 范围、裁定与实现

拥有 internal/repo/*；只另减 lifecycle/legacy_gate_allow.txt 以及本报告/behaviour-changes.md。没有修改 model、任何其他包生产文件、任何冻结语料、Python oracle 或 pyref 期望；没有非本包测试文件改动。需要资源 SetJSON 的地方复用 model.Marshal、model.Fields.Set、json.Unmarshal 的既有 codec，不增加 parser、动态文档抽象或调用方 codec。

协调者裁定：旧同名入口留在 legacy.go 作转码 facade，新名称就是最终名称，不使用 Typed/Native/V2 后缀。ResetAllJSON 实际返回结果文档 JSON，因此保留此名。旧 hook fallback 只在 legacy.go；typed hook 优先且每操作只触发一次，覆盖 planner、四个脱敏入口、publication lock、commit observer。注册端由后续 owner 迁移。

- 全量导入/导出/重置、schema-2/single-profile 合并、profile clone/import/client import/metadata、规则库文件+DB 批次、节点删除主实现均 typed；legacy wrapper 仅转码委托。旧 resolved-config 事务也委托同一 native 编排，保留同锁/同提交点/返回代际，不在 legacy 层重复 hydrate 业务。
- UpdateConfig / UpdateSharedConfigs 由协调者追加，给 W4 的 adapter/compose_adapter/rulelibrary editWithProfiles 使用；回调读 hydrate 后 rule_library、system、agents，与 shared 修改前/后的投影。只写 ProfileFields/SharedFields 中回调实际变化的成员；hydrate 的源不落回 profile，未改 opaque 字节不动。
- W3 追加依赖：SharedConfig + SaveSharedRecord 捕获 request Scope baseline、保留 catalog 三路合并；ResourceUsage 返回可直接 HTTP JSON 编码的原生 DTO。
- decodeEntry 只解 model，旧 jsonx 文档延迟到 legacy accessor 首次需要时生成；native export/update 的负控证明不会物化 legacy 文档。store_rows 元数据使用 RawMessage；file/merge/defaults/validate 的实现退出 jsonx/pystr。
- 本包从 allowlist 删除 **11 行，新增 0 行**。剩余总数 836（P0 847）：retired-import=754、retired-directory=2、retired-symbol=31、legacy-file=49、testjson-import=0。

## 最终 typed API（供 W3–W7 简报直接引用）

以下除明确包级外均为 `(*repo.Repository)` 方法；签名中的 model 为 internal/model，ctx 为 context.Context。

```go
ExportAllJSON(ctx context.Context, desensitize bool) (json.RawMessage, error)
ImportAllJSON(ctx context.Context, raw json.RawMessage) (json.RawMessage, error)
ResetAllJSON(ctx context.Context) (json.RawMessage, error)

ProfileMetadataRecord(ctx context.Context, id string) (ProfileInfo, error)
CreateProfileRecord(ctx context.Context, input ProfileCreation, cloneFrom string) (ProfileInfo, error)
CloneProfileRecord(ctx context.Context, sourceID string, input ProfileCreation) (ProfileInfo, error)
UpdateProfileMetadataRecord(ctx context.Context, id string, input ProfileMetadataUpdate) (ProfileInfo, error)
ExportProfileJSON(ctx context.Context, id string) (json.RawMessage, error)
ImportProfileJSON(ctx context.Context, id string, raw json.RawMessage) (*model.Profile, error)
ImportClientProfileRecord(ctx context.Context, input ProfileCreation,
    build func(context.Context, *model.Shared) (*ClientProfileImport, error)) (*ClientProfileResult, error)
ListProfileRecords(ctx context.Context) ([]ProfileListing, error)
ProfileAgentBindingsRecord(ctx context.Context, id string) (ProfileBindings, error)
SaveProfileFieldsJSON(ctx context.Context, id string, raw, baseline json.RawMessage) (*model.Profile, int64, error)

    sharedEdit func(context.Context, *model.Shared) error,
```

包级 SharedConfig 在 Scope 中捕获不可变 baseline，包级 SaveSharedRecord 的 baseline=nil 会使用它，成功后清理 Scope；方法级 nil baseline 表示按 supplied revision 校验，无 Scope 隐式行为。Config / PublishConfig / ReadSharedBytes 已有且可直接用；SaveRouterPublicationJSON 现为全 native 实现，签名不变。Options 新字段 DefaultSettings / InitialSettings 均为 `func() *model.Config`；OpenDefault 已使用它们，旧 factories 留待消费者迁移后删除。

DTO：ProfileCreation={ID,Name,Description string}；ProfileMetadataUpdate={Name,Description *string}（nil 表示未提交该字段）；ProfileInfo={ID,Name,Description,CreatedAt,UpdatedAt string}。ClientProfileImport={Shared model.Shared,Profile *model.Profile,Details model.Fields}，Result={Profile ProfileInfo,Details model.Fields} 且 MarshalJSON 沿用 diagnostics+profile 合并形状。ProfileListing 嵌入 ProfileInfo 并含 Revision int64、IsDefault bool、BoundAgents []AgentBinding；ProfileBindings={Profile ProfileInfo,Agents []AgentBinding}。AgentBinding 的 ID/Name/Host/Port/ServiceType 为 RawMessage，只公开身份。

Usage={Kind,ID,Name string; ProfileID,ProfileName *string}，两个 profile 字段 `omitempty`，指针保留 present 空字符串。kind 使用 SharedFields 名称。NodeDeletionPreview={Nodes []DeletionNode,Usages []DeletionUsage,Groups []DeletionGroup,Blockers []string,EmptySources []string,Confirmation string}；DeletionNode={ID,Name}，DeletionUsage={Kind,ID,Name}，DeletionGroup={ID,Name,ProfileID,ProfileName} 均 string；形状沿用旧 HTTP 预览。调用方负责 IDs 的请求形状校验。

Hooks 使用 `Hooks{RecordHooks: repo.RecordHooks{...}}`：

```go
JobLockRecord func(context.Context, string, string, model.Router) (func(), bool)
ConfigurationCommittedRecords func(*Repository, *model.Document, *model.Document)
PlanNodeDeletionRecords func(*model.Document, []string) (*NodeDeletionPreview, *model.Document, error)
SanitizeExternalDocument func(context.Context, *model.Document, model.SystemConfig) (*model.Document, error)
RedactOxidnsJSON func(json.RawMessage) (json.RawMessage, error)
RedactRoutersJSON func(json.RawMessage) (json.RawMessage, error)
RedactEasytierJSON func(json.RawMessage) (json.RawMessage, error)
```

planner 候选由协作者拥有；snapshot/committed 参数按只读契约使用。JobLock 仍 nonblocking，失败整笔拒绝，release 在 commit observer 前。Routers redaction 用 RawMessage，保留旧 hook 的合法标量返回形状而不强制为对象。
