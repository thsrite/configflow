## 结果

配置空间：从默认配置空间创建副本 `l4gw`（有完整的订阅、策略组和规则）。网关接入设置：选择性接管，IP 网段只选 Telegram，代理规则集 Grok/Proxy，直连规则集 ChinaMax/LabJSON，本地 DNS 用 DoH-by-IP。保存前提示「已开启登录验证，请先在系统设置中配置订阅令牌（config_token）」，生成令牌后保存成功。

### I：IPv6 就绪（A23）

环境：CHR VM 233（RouterOS 7.25.1，WAN ether1 10.97.0.133 在 cfgt，LAN ether2 192.168.94.1/24 + `2001:db8:94::1/64` 并发 RA 在 cfl4），REST 账号 `cf`。cfl4 是运行时创建的隔离网桥，宿主机上没有地址（关掉了它的 IPv6）。Mihomo 主机 CT 234（Debian 12，192.168.94.10，SLAAC），Agent 1.8.61-go，安装时装核心。面板 CT 加了到 192.168.94.0/24 的静态路由（经 CHR）。为了让 ROS 的 IPv6 默认路由「生效」，在 cfgt 网桥内配了一段实验 IPv6（CHR `2001:db8:97::133`，面板 CT `2001:db8:97::120` 作为假上游）；实验网没有 IPv6 互联网。

| # | 结果 |
|---|---|
| I1 | 通过：GET 就绪检查对着真实主机和真实 ROS 给出逐项结论（主机地址、RA 默认路由、转发/RA 参数、持久化；ROS 的 WAN 默认路由、RA、DNS、防火墙/NAT 静态判断、各类 ICMPv6/DHCPv6 入站路径）。打开 Mihomo IPv6 和 DNS IPv6 之后 `can_prepare` 为 True。prepare →「已补齐可自动处理的主机配置；ROS 路由请到上游路由差异报告预览并发布」，主机 `ip_forward=1`、`ipv6 forwarding=1`、`eth0.accept_ra=2`，写入 `/etc/sysctl.d/99-configflow-ipv6.conf`。重启主机后参数保持，SLAAC 地址和 RA 默认路由正常，Mihomo 和 TUN 正常，检查项全部 ok |
| I2 | 通过：先取检查 token，在 ROS 上加一条 IPv6 路由，再用旧 token prepare → 409 `CHECK_CHANGED`「设备、草稿或路由状态已变化，请重新检查后补齐」 |
| I3 | 未覆盖：客户端链路验收需要真实的 IPv6 互联网、真实节点和检测客户端，实验网没有 |
| I4 | 通过（自动验收部分）：发布带 `ipv6_verification_requested: true`；发布成功后 5 s 内出现一次验收（单个 run_id，之后 `checked_at` 不再变化，没有重复启动）。结论 `error`「主机自检完成」：主机、路由器、设备配置、运行中 IPv6 开关、DNS A 查询均 ok；代理 HTTP 访问 error、节点 IPv6 传输 unknown（合成节点、没有 IPv6 互联网），并明确提示「尚未配置检测客户端」。超过 30 条历史的裁剪没测（需要 31 次发布，由自动化覆盖） |
| I5 | 部分：把 ROS LAN 前缀从 2001:db8:94 换成 2001:db8:95，主机拿到新地址（旧地址 deprecated）。普通 GET 仍返回上次结论（`cached: true`、旧 token、没有 `stale`）：缓存只看面板侧依赖，看不到主机前缀变化；刷新后给出新结论和新 token。记为 L4-O2 |
| I6 | 移到 L5，与 R14 规则同步一起做 |

## 观察

- L4-O1：G3 中从另一个 IP 使用同一 capability，面板拒绝登记的原因（409「设备身份、地址、服务类型或配置空间已改变…」）只写在 Agent 日志里，安装脚本终端只显示「Agent 启动后未保持运行」；且拒绝发生在核心下载安装之后，核心留在那台主机上。
- L4-O2：IPv6 就绪检查的缓存只看面板侧依赖；主机前缀变化后普通读取仍显示「沿用上次检查」，需要手动刷新。
- L4-O3：新设备第一次发布要从 GitHub 下载 Geo 文件，实验网里 ASN 一次下载用了 7 分钟，期间发布停在 preparing。用户侧可以用「GitHub 代理域名」缓解，界面已有提示。
- L4-O4：网关会话中断后继续发布，以及 A17 失败消息里，都直接拼接了内部英文「Preparation interrupted before upload; current service unchanged」（同 L3-O5）。
