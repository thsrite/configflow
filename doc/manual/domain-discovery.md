# 域名发现

这个页面帮你找出“规则还没照顾到的网站”和“直连失败的网站”，再决定是否补进规则。它依赖当前配置空间中的 Mihomo Agent，单独安装管理面板不会产生记录。

记录网站域名、命中规则和失败情况，不记录完整网页路径或访问设备 IP；采集记录保留七天。域名是 `example.com` 这样的名称，不是你打开网页的完整地址。

## 第一步：开启采集

在设备列表中为需要观察的 Mihomo Agent 打开采集。关闭后停止继续采集；清空数据用于删除已经收集的记录，两者作用不同。遇到“控制接口密钥错误”或“连不上 Mihomo”，先处理 Agent 与核心连接，不要靠清空记录解决。

推荐先只开启你实际使用的一台设备。采集只反映经过它的连接，没有记录也可能是访问根本没有经过 Mihomo。

## 第二步：准备接收新规则的清单

| 选项 | 怎么填 | 不设置的结果 |
| --- | --- | --- |
| 默认直连规则集 | 选择可编辑的本地内容规则集，或一键创建专用规则集 | 无法把直连建议写入默认目标 |
| 默认代理规则集 | 选择可编辑的规则集，并核对它对应的策略组 | 无法把代理建议写入默认目标 |
| 一键创建 | 建立空规则集，并在最终兜底规则之前加入对应规则 | 只建立规则位置，不会自动判断全部网站 |

建议专门使用“域名发现-直连”和“域名发现-代理”，方便以后回看和撤销。代理目标要指向有可用节点的策略组，不能只创建一个空名字。

## 列表和按钮

| 控件 | 作用 |
| --- | --- |
| 24 小时 / 7 天 | 改变查看的时间范围 |
| 未覆盖 | 找还没有明确规则覆盖的网站 |
| 直连失败 | 找观察到直连失败的记录；不等于一定应该走代理 |
| 全部 / 已忽略 / 已加入 | 分别看全部记录、暂时不处理的记录、已经加入规则的历史 |
| 搜索 / 勾选 / 全选 | 找目标并指定批量操作范围 |
| 展开域名 | 看它下面具体出现过的子域名 |
| 探测 | 实际尝试直连和代理，给出建议；会产生测试请求 |
| 识别网站 | 请求网站首页，补充名称等信息；批量最多处理 30 个 |
| 采纳建议 | 把探测建议写入相应默认规则集；先检查建议和目标 |
| 加入代理 / 加入直连 | 按你的选择写规则，不必接受自动建议 |
| 忽略 / 取消忽略 | 暂时移出待处理列表或放回，不会拦截网站 |
| 撤销 | 从“已加入”历史中撤销对应添加；需要再确认部署后的变化 |

手机上每个域名排成两行：第一行域名、连接数和最近出现时间，第二行标签、子域数、直连失败次数和当前走向；探测、地区检测、加入代理 / 直连、网站信息和忽略收进行尾的 **⋯** 菜单，作用与桌面按钮相同。“已加入”历史同样两行，行尾保留 **撤销**。

添加整个域名后缀可能覆盖它下面的多个子域名；只想处理某个子域名时，选择对应的精确域名规则。一次访问失败可能只是网站临时故障，建议先探测再添加。

写入的是 ConfigFlow 中的规则。已经发布的配置若引用了对应规则集，可按其更新机制读取；新建规则集或改了配置结构时，需要重新生成并发布。显示“待部署”时，按页面提示处理，不能认为“已加入”就一定已经影响设备。

## 自动探测和自动采纳

| 开关 | 当前初始值 | 打开后 | 关闭后 / 建议 |
| --- | --- | --- | --- |
| 自动探测 | 关 | 定期分批测试尚未覆盖的网站，并安排复查 | 仍可手动探测；初次使用先观察手动结果 |
| 自动采纳 | 关 | 自动把达到置信度要求的建议写入默认规则集，需要先打开自动探测 | 保留建议，等你确认；不撤销已经写入的规则 |
| 最低置信度 | 90，可选 80 / 90 / 95 | 数字越高，自动采纳要求越严格 | 不是“网站可用率”；初次不建议降低后直接无人值守 |

自动探测约每十分钟处理一批；较早的记录会按复查安排重新测试，不会一次性测完所有网站。测试使用 Agent 自身的 Mihomo，比较直连与默认代理规则所对应的策略，因此该设备的网络、策略组和所选节点都会影响结论。

推荐先开启采集、手动探测少量网站，确认目标规则集正确后再考虑自动探测。自动采纳建议继续保持关闭，直到你已看过一段时间的结果。

## 地区限制：某个网站只在部分出口可用

“地区限制”用不同地区的代表节点做比较，不会为了测试就切换你正在使用的策略。

| 选项或按钮 | 作用与推荐 |
| --- | --- |
| 开启区域检测 | 初始关闭；需要比较地区差异时打开，并按提示更新 Agent、重新发布一次 Mihomo 配置 |
| 检测入口端口 | 初始 `17999`，仅供设备本机测试；避开已有端口。输入后离开输入框或按回车保存 |
| 检测服务 / 对域名检测 | 实际请求目标服务，比较直连、当前策略及各地区代表节点 |
| 结果中的 `—` | 尚无有效结果，不能当作“该地区不能用” |
| 指定走向 | 选择希望这个服务使用的策略组；先确认该组确实能提供所需地区的节点 |
| 写入 | 建立或更新该地区规则集，放在默认代理规则之前；首次新增后需要发布配置 |

检测会参考网站返回的限制文字、跳转和响应状态，因此“疑似区域限制”只是线索。它不能证明该地区所有节点都可用，也不自动为你购买或创建节点。先手动确认，再点“指定走向”和“写入”。
