# ConfigFlow 使用手册

从安装到日常维护，一步一步完成。这里先说明你要得到什么结果，再介绍按钮和选项；遇到界面中的专业名称，会在旁边解释。

> 文中“推荐”是对应场景的建议，“默认”是新配置的初始值。旧配置会保留自己的选择，请不要因为默认值不同就直接覆盖。

在电脑上使用管理面板时，点击右上角的文档图标（“查看文档”），会在新标签页打开[这份使用手册](https://thsrite.github.io/configflow/)。

![管理面板顶栏，右侧纸张图标是查看文档入口](img/guide/panel-header-docs.jpg)

## 第一次使用，按这个顺序

1. [安装 ConfigFlow 管理面板](guide/install.md)。先让浏览器能打开它，并把账号和数据保存位置安排好。
2. [首次使用向导](guide/first-run.md)。选使用方式，填订阅，准备一份配置。
3. [安装被管理设备](guide/agent-install.md)。按你实际拥有的设备选择单独安装、同机安装、Docker 或已有程序接管。
4. 先让一台测试设备使用新配置，检查正常后再安排其他设备。遇到问题按 [排查顺序](guide/troubleshooting.md) 处理。

如果只是生成配置，下载给手机或电脑客户端使用，第 3 步可以跳过。不要为了“功能齐全”把所有选项都勾上。

## 看懂文档里的提醒

**推荐选择**会写适用条件，不能代替你已有的网络安排。**保存**通常先更新面板里的草稿；**发布、应用、启用、重启**可能影响实际设备，操作前阅读该页说明。**测试、检查、预览**只有在该页明确说明后，才能判断它是否会写入设置，不要仅凭按钮名字推测。

文中的地址都是示例。请按角色替换成自己的地址：面板地址、被管理设备地址、主路由地址和双机共用地址不是同一个东西。
